# Data protection and public-release safeguards

This repository is intended to share scientific analysis code, documentation, and selected aggregate statistical summaries.

Individual-level datasets, source spreadsheets, identifiable participant information, credentials, confidential correspondence, and unpublished manuscript drafts must not be uploaded.

Aggregate statistical outputs may be included only after verification of their contents and authorization for public dissemination by the responsible research team. Verification of numerical agreement with a manuscript is not equivalent to disclosure authorization.

Notebook execution outputs, local input files, and environment secrets should remain excluded from the public repository. Review filenames, code comments, embedded paths, and notebook metadata before each release.

The Git history must also be reviewed, since deleting a file from the current branch does not remove it from previous commits.
